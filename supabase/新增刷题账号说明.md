# 新增独立刷题账号

本次目标账号为 `10001`。它与 admin 共用题库，学习记录、错题、收藏、笔记、考试和设置各自独立，没有导入、修改、删除共享题库的权限。

1. 打开 Supabase 项目的 SQL Editor，新建查询，粘贴 `升级_共享题库与独立账号.sql` 的全文，点击 Run。该脚本可重复执行，会保留原管理员记录，并迁移已上传的题库。
2. 打开 Authentication → Users → Add user → Create new user。邮箱输入 `10001@tijian.local`，输入你设置的初始密码，勾选 Auto Confirm User，点击 Create user。不要改动现有 admin 用户。
3. 将更新后的 `app.js`、`cloud.js`、`sw.js` 上传替换 GitHub 仓库根目录下的同名文件，等待 GitHub Pages 部署完成。SQL 文件只在 Supabase 执行，不作为网页脚本加载。本地网页刷新后可直接使用更新代码。
4. 先用 admin 登录并等待显示已同步，确保本机尚未上传的题库发布到共享库；退出后用 `10001` 及其密码登录。普通账号的学习进度从零开始。

账号实际创建和数据库升级需要在 Supabase 后台完成，仅修改网页不会创建 Auth 用户。密码不写入源代码或部署文件。
